# YHCB BuyGearPump Landing Page

## Purpose

这是 BuyGearPump 的 YHCB 产品广告落地页项目，目标域名为：

```text
https://yhcb.buygearpump.com/
```

页面用于承接广告流量、展示一个具体 YHCB 型号的不同尺寸，并收集询价线索。

## Relationship to the main site

主站位于：

```text
D:\code\buygearpump
```

主站负责完整的产品目录、技术资料、博客、FAQ 和自然搜索。YHCB 项目负责广告首屏、产品卖点、尺寸选择和询价转化。

YHCB 页面可以链接到主站的完整产品资料，但不应依赖主站的运行时脚本、主题或图片 URL。

## Technical direction

- Static site generated by Hugo.
- No full Hugo theme.
- One landing page at the site root.
- One product family with multiple size variants.
- Minimal CSS and JavaScript.
- Form submission through the approved lead endpoint.
- GA4 and advertising conversion tracking through documented events.

## Before implementation

The exact YHCB model name, size table, verified product images, form destination, analytics identifiers, and hosting provider still need to be confirmed. Until then, agents must use placeholders that are clearly marked and must not invent specifications.

## Cloudflare Pages test deployment

This repository is intended to be connected to Cloudflare Pages through GitHub.

- Framework preset: `Hugo`
- Build command: `hugo --minify`
- Build output directory: `public`
- Production branch: `main`
- Custom domain: `yhcb.buygearpump.com`
- Hugo version: `0.151.0` or newer

The current page is explicitly a test page. Its quote form does not send lead data until an approved endpoint is configured.
